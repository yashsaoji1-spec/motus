Motus Medicine

A three-minute walkthrough

Home exercise programs, from the therapist's side and the patient's.

For the therapist

  • The whole caseload on one screen, with patients who need attention surfaced automatically
  • Build a program in seconds — reps, sets, frequency, rest, and a note
  • Record a demo video once so the patient sees the movement done right
  • See what happened between visits, per set

For the patient

  • Installs from the browser — nothing to download
  • Today's plan, and a guided session that counts sets and rest
  • Record a set and log reps and pain in two taps
  • Watch their own pain trend over time
